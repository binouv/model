# R04-H1c — завершённый GPU-прогон: результат оператора (12 октября 2026)

**Статус:** пользователь сообщил о завершённом научном запуске RTX 3090; **гипотезы C0, C1 и C2 не подтверждены**. Этот документ — отчёт об исходных измерениях пользователя; он **не заменяет** оригинальный `metrics.json`, `predictions.jsonl`, checkpoints и кэш скрытых состояний.

## Происхождение

- Локальный коммит исследователя: `1e4696c` (~79 МБ), **не опубликован в GitHub по причине HTTP 403 для NeoXider**. У подключённого к этому чату `binouv` есть право записи, но локальный объект Git не виден через API, пока байты не загружены.
- Замороженный учитель: `Qwen/Qwen3.5-4B`, revision `c7429d5a8ed57f4a9cfdaf1af76a8943eba0ae97`; RTX 3090, BF16.
- Новый набор из 1 700 задач, train/val/test = 1 200/200/300, SHA256 canonical `ac764eed8a0e06486dee8452219293941e208618fd95cbfa7495395f71184af7`. Исключены все сочетания исходного H1 и H1b.
- Извлечено 1 700/1 700 hidden states до первого токена ответа; **префикс** SHA256 извлечённых признаков: `4c489175` (полный SHA256 не предоставлен), пик VRAM ~9,0 GiB.
- Тесты: 13/13 локально. Обучение с глубинами T=0/2/8 и источниками Qwen hidden, структурированные данные и lexical hash; seeds 11/22/33. Контроли регистрировались заранее.

## Корректная интерпретация

Вывод ограничен конкретным семейством двухшаговых модульных задач и замороженной Qwen3.5-4B. Нельзя утверждать, что в любых hidden states LLM не существует информации о будущем. Однако все три инженерно независимые попытки H1, H1b и H1c, согласно доступным измерениям, **не предоставили положительного доказательства готового двухшагового ответа после одного prefill**. Обученный маленький T=8 вычислитель сам по себе не улучшил качество.

В R02–R03 результаты касались извлечения **явных фактов из вопроса**, а R04 — вычисления двух новых цифр. Этот контраст имеет научное значение: наличие компонентов задачи в контекстном состоянии не тождественно выполненному решению.
