# FlyGraph: решения по обзору Qwen, DeepSeek и малых LM

Проверено 2026-09-25. Первоисточники и просмотренные участки кода: `REFERENCES.json`.
Это обзор и подготовка экспериментов, не доказательство, что заимствования уже улучшают FlyGraph.
Текущий G1 обучается без изменения архитектуры; его единственная абляция — отключение сообщений графа.

## Аудит текущего G1

309 993 253 обучаемых параметра. Авторегрессивный выход по всему словарю 8192.
Уже есть GQA, RoPE, RMSNorm, SwiGLU, tied input/output embeddings.
Но 4.819M graph workspace — синтетический readout после 12 Transformer-блоков.
Он повторяет два внутренних раунда отдельно на каждом токене, НЕ переносит состояние между токенами.
ProtectedMemory — отдельный программный API; LM ещё не обучена вызывать его.
KV-cache, точный журнал фактов и межэпизодная память — разные понятия.
Корпус 3 742 193 токена, протокол только 98 304 предъявления: это bootstrap, не широкое предобучение.

## Qwen3.5-4B

Читать конкретный `Qwen/Qwen3.5-4B/config.json`, а не общие MoE-тезисы семейства.
4B имеет dense FFN, 32 слоя с тремя linear-attention слоями на один full-attention,
output gating и tied embeddings. В Transformers просмотрены Q/K head normalization,
разделение query/gate и sigmoid gate перед output projection; также recurrent-state cache
и float32 decay GatedDeltaNet. Это model/inference implementation, не весь закрытый training pipeline.

Первая узкая переносимая идея — gated attention. Оригинальный прототип
`experiments/g2_gate/headwise_gate.py` использует headwise `2*sigmoid`, а не elementwise gate Qwen.
Нулевая инициализация сохраняет исходную функцию точно. Добавляет 442 656 параметров
к G1, всего 310 435 909. В текущий train не установлен; correctness tests не равны learning gain.
Q/K normalization — отдельная будущая проверка, не одновременная незаметная смена блока.

Для памяти перспективен гибрид причинной рекуррентной матрицы и редкого full attention.
Состояние должно переноситься между токенами и сбрасываться между документами;
нужны тесты full/chunk/cache equivalence. DeltaNet хранит сжатый непрерывный state,
а НЕ точные адресные записи. Защищённый журнал фактов остаётся отдельным.

Не копировать vocab=248320 без расчёта: при D=1536 одна tied embedding — 381 419 520
параметров, больше нынешнего G1. Следующая новая серия может измерить 16K/32K BPE
на сбалансированном RU/EN/code корпусе. Это новая конфигурация, не бесшовная замена tokenizer.

## DeepSeek-V3 и R1

Изучены MLA и naive/absorb cache в официальном V3 inference/model.py, MTP в отчёте,
и distillation в R1. Наибольший приоритет — разнообразные проверяемые решения:
teacher генерирует задачи/решения, независимый verifier пересчитывает арифметику,
воспроизводит memory trace и проверяет код в изолированном исполнителе.
Самооценка teacher не заменяет проверку; gold test нельзя превращать в train.
В этом run внешние модели/API не вызывались и их веса не импортированы.

MTP — отдельный кандидат: одна дополнительная будущая позиция с общей embedding/output.
Не подавать future gold в основной causal inference. Это дополнительный supervision,
а не автоматически доказанный reasoning gain.

MLA копировать по размерам нельзя: наш GQA cache хранит 2*4*64=512 чисел на token/layer.
DeepSeek kv_lora_rank=512 плюс rotary64 дали бы 576, то есть больше.
Нужен меньший подходящий rank и парная проверка качества/памяти.
MoE и FP8 пока не приоритет: отдельно считать total/active parameters и фактические
FLOPs. Неиспользуемые experts не являются прогрессом интеллекта.

## SmolLM2 и recurrent-depth LM

Официальная карточка SmolLM2-360M сообщает 4T training tokens с образовательным,
web и code корпусом. Это не нижняя граница нашего бюджета, а пример роли данных.
Модель английско-ориентирована; её готовая инициализация была бы явно labelled derived branch.
В Scaling up Test-Time Compute with Latent Reasoning полезна идея shared recurrent
thinking block и переменного числа итераций. Общие веса не делают повторный forward бесплатным.
Два раунда G1 graph readout не воспроизводят целиком этот метод.

## Последовательность решений

Закончить G1 с неизменным протоколом; затем парное gate-продолжение с одинаковыми
minibatches и control gate=1. Новые данные важнее следующего увеличения числа слоёв:
естественная RU/EN проза, разные формулировки, проверяемые программы, независимые
генераторы и permutation-safe memory. Сохранять защиту C1 от storage-order shortcuts.

Планы 347.742M / 545.947M / 793.704M с 32K словарём — только расчёты, не обученные модели.
С Qwen сравнивать реальные ответы/pass@1/trace при одинаковых задачах и правилах инструментов.
NLL разных tokenizer напрямую не сравнивать; требуется общий unit, например bits/byte.
