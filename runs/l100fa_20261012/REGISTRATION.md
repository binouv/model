# L100FA — full-parameter SFT for tool-using agent (preregistered 2026-10-12)

**This registration is published BEFORE new optimizer updates or looking at held results.** The scientific goal remains general superiority over Qwen3.5-0.8B, **not established**.

Parent: verified 100,028,328-parameter L100EC curriculum BF16, SHA256 `07e33eb2c6aab5727fbb72c0b403bc83ca8e5695d379106af089b27baf995b25`. Full FP32 weight warm-start with **fresh** Adafactor; optimizer/RNG of L100EC not available (not exact resume). All 135 original parameter tensors trainable, no frozen LoRA-only façade; same 8192-token UTF8-fallback tokenizer and 14-block delta/GQA backbone.

**Finite protocol:** 256 Adam/Adafactor-style optimizer updates (PyTorch `torch.optim.Adafactor`), batch 2, LR 0.00012, gradient clipping 1.0, seed 1212401, CPU 4 threads BF16 autocast with FP32 delta operator. Native checkpoints after completed steps 64/128/192/256; FP32 model.safetensors + optimizer, scheduler/step, Python/Torch RNG, immutable data hashes, sampler cursor. Separate BF16 export is inference-only. Fixed endpoint 256, no held-based cherry picking.

Training: deterministic independent synthetic task groups in RU/EN across four agent action families: calculator, list sum, last-write memory, restricted Python arithmetic trace. Each task yields two autoregressive supervised states: first `CALL ...` using only user prompt, then `FINAL ...` conditioned on the tool's observed result. Every fifth update includes historical L100A training-replay tasks (source SHA256 `2e63cac3c4376f7635e36de9d9158f27baba6cd22f5d61eaa8a5d02576e74907`) to constrain forgetting. Tool executor performs bounded, explicitly engineered arithmetic/state transitions; the LM must still generate tool name and valid arguments. Executed tools may not call shell/network or arbitrary Python.

Held: 48 disjoint agent task groups (12 per family), independent seed1212402, plus 24 historical regression tasks; fixed prompt-only greedy full-vocabulary decoding max48 tokens with EOS required. Evaluate the identical frozen parent and final child on exact tool-call correctness, tool validity, end-to-end two-turn result and synthetic regression strict answer parsing. Preserve every raw generation and stop reason. Main gate: +10pp end-to-end agent accuracy relative to parent, and no more than 2pp regression loss. Report if gate fails. No new Qwen run is part of this experiment. Confidence intervals and one-seed limitation disclosed. Generated test values/hashes published before evaluation; no model selection on held.

Publication: all source/data/raw predictions/tests/reports + actual model/optimizer/RNG bytes, 80MB default binary Git parts **strictly <90MB** with SHA256 and readback, according to `FLYGRAPH_RUN_POLICY.md`. In-progress 64-step recoveries are not scientific successes; record incomplete states accurately. No claim of universal agency or broad intelligence; restricted tools and tiny held samples limit validity.
