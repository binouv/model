## Гипотеза и диагностика

На новом dev исходный EXT2 сохранял выбранное содержание ответа при всех циклических перестановках только в **1/64** вопросах. После выбранного EXT3: **0/64**. Это поддерживает диагноз позиционного смещения; сама инвариантность ещё не доказывает правильность ответа.

Каждый update содержит все4 циклических порядка одного опубликованного OpenBookQA вопроса и оба порядка одного PIQA вопроса: целевые буквы внутри каждого набора точно сбалансированы. Используется cross-entropy среди допустимых меток, без доминирования EOS. Вес loss:0.4 OpenBookQA,0.4 PIQA,0.2 Alpaca assistant/EOS. Нет придуманных вопросов, вариантов или gold-ответов: переставлены существующие варианты и точно перенесён индекс правильного ответа. Ограничение обучения верхними двумя блоками снижает стоимость эксперимента и сохраняет нижние представления; это не полноразмерное переобучение всех100M весов.

Выбор checkpoint: минимум среднего normalized choice NLL на32 новых OpenBookQA и32 PIQA dev с полным набором циклических порядков (192 представления). ARC dev не участвовал в выборе. Parent разрешён как step0. Формат и рост энтропии сами по себе не являются успехом. После открытия test обучение/выбор/протокол не менялись. Test original order, одинаковые prompts и greedy16 новых токенов по полному словарю с EOS у всех моделей. Ranking использует log p одной метки; ties по порядку вариантов, greedy ties по token ID.

## Источники и независимость

Train: по768 исходных OpenBookQA/PIQA/Alpaca из прежнего EXT2 training; повторное использование train явно разрешено, исключены новые holdouts. Новый MCQ dev96 и test384 исключают прежние MCQ train/dev/test и ARC128 по нормализованному stem. Новые Alpaca dev32/test64 исключают прежние EXT/EXT2 train/dev/test по ID и нормализованным инструкциям. PIQA test — новый зарезервированный размеченный validation subset, не hidden official test. OpenBookQA и ARC-Challenge используют официальные test. Неизвестная историческая pretraining contamination и перефразы не исключаются. Проверки известных пересечений: `metrics/overlap_audit.json`.

Фиксированные источники: [OpenCompass release0.2.2.rc1](https://github.com/open-compass/opencompass/releases/tag/0.2.2.rc1), [OpenBookQA](https://github.com/allenai/OpenBookQA), [PIQA](https://github.com/ybisk/ybisk.github.io/tree/master/piqa), [ARC](https://huggingface.co/datasets/allenai/ai2_arc), [Alpaca revision761dc5b](https://github.com/tatsu-lab/stanford_alpaca/tree/761dc5bfbdeeffa89b8bff5d038781a4055f796a). SHA, seed20261025, original IDs и записи — `data/manifest.json` и JSONL. Лицензии: Apache2, AFL3, CC-BY-SA4, CC-BY-NC4 соответственно; research-веса сохраняют некоммерческие ограничения Alpaca.

## Сохранность и ограничения

Native FP32 weights и AdamW, CPU BF16 autocast, FP32 delta state. AdamW5e-5, warmup32, cosine→10%, betas(0.9,0.95), WD0.01, clip1. Checkpoint64, атомарная запись/strict reload; избыточные recovery pruned только после подтверждённого преемника, hash receipts сохранены. Native resume из step64 воспроизвёл шаги65–128 с точным совпадением64 losses/gradient norms и всех135 тензоров. Родительские веса сохранены в предыдущем опубликованном EXT2; новые final/selected bytes и optimizer/RNG/config/data identity сохранены без квантования, части<90MB. Статус push/readback проверяется отдельно по `PUBLICATION.json`; этот отчёт сам по себе не подтверждает публикацию.

Один seed и три небольших английских MCQ набора не оценивают универсальное рассуждение, русский язык, код, память или мультимодальность. Сырые примеры Alpaca не отбирались по качеству: первые4 test-записи, одинаковый бюджет32 токена. Отрицательные результаты сохранены.
