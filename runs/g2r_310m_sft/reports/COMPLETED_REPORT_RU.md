# FlyGraph G2R-310M: итог парного обучения

**Два обучения завершены. Основная гипотеза не подтверждена в данном протоколе.**

## Что проверено

Одна гипотеза: supervised loss только по проверенному ответу улучшает свободную генерацию по сравнению с loss по всей последовательности. Модель, исходные веса, примеры, minibatches, learning rate и число обновлений одинаковы; контроль меняет только область supervised loss.

Две модели по 309 993 253 обучаемых параметра. Каждая получила 256 optimizer updates, 1024 предъявления, 891 уникальный пример, 49 716 входных токенов. Main supervised tokens: 5139; контроль: 49 716. Одна инициализация seed7201. Старт — фактически доступный G1 step192 BF16, преобразованный в FP32 с новым Adafactor. Это не точный resume старого G2 и не независимое повторение его seed.

Полный словарь8192, greedy generation, максимум8 новых токенов, без инструментов. Все правильные ответы укладываются в лимит. Вызов модели получает только prompt, не gold/case. Main vs control: на IID2wins/2losses, delta0pp, exact paired p=1.0. Main vs G1: delta2.5pp,p=.125. Все четыре заранее заданных порога эффекта не выполнены. Снижение NLL само по себе не считается reasoning-успехом.

Response validation NLL: 4.1464 до обучения, 1.0787 у main, 1.0950 у контроля. У main на teacher-forced validation правильно15/79 числовых токенов, но115/120 пробелов/EOS. Значит, освоение формата существенно опережает вычисление ответа. Это диагностика, не новая гипотеза и не accuracy целых задач.

## Сохранность и ограничения

Все18 инженерных тестов прошли; все70 финальных FP32/BF16 shards проверены по SHA256 и конечности значений параметров. Обе точности повторно загружены:10 запросов на каждую модель/точность, всего40 проверок, без расхождений с исходными FP32 prediction. Это не повтор всех400 тестов в BF16. Состояния optimizer/RNG сохранены. Все финальные тесты завершены полностью, partial/timeout в агрегаты не включались.

Данные синтетические. Их объявленные semantic groups не пересекаются, но дополнительный аудит нашёл некоторые эквивалентные арифметические случаи в SFT train и некоторые в G1 corpus. Наличие в corpus не доказывает фактическое предъявление в G1. Общая стартовая база сохраняет смысл парного сравнения, но тест нельзя называть полностью свободным от семантического пересечения. Есть отдельная диагностика исключения известных совпадений.

Текущий граф — синтетический readout внутри токена, а не долговременная межтокенная память. 1024 предъявления не позволяют оценивать потолок310M модели. Код Qwen/DeepSeek/Engram/MobileLLM-R1/TRM изучен; выводы в research/BORROWING_DECISIONS_RU.md. Эти механизмы не были незаметно подмешаны в текущее обучение.
