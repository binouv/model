# FlyGraph G12 — preregistered capacity learnability screen

G7R and G11R both failed their registered primary gates, and both left arithmetic/code near zero. G12 therefore stops stacking more trace or recurrence mechanisms and tests the simpler possibility that the sub-million byte model is below the capacity/optimization regime needed for these tasks.

Paired arms keep the same causal-hybrid `dada` architecture, byte259 completion objective, batches, examples and 2000 optimizer updates. Only width changes: 469,648 parameters versus approximately 2,118,928. This is parameter/capacity scaling, **not compute-matched**. Fresh canonical groups must be disjoint from reconstructed G5S, G7R and G11R groups before any training.

Primary target is arithmetic+code-trace IID exact. Registered gate: at least +5 percentage points for wide vs small, positive direction in at least two of three seeds, plus transfer/regression safeguards. Fixed endpoints only; held never selects a checkpoint.

No data or training result exists yet in this namespace. Confirmation would still be narrow synthetic capacity evidence, not Qwen3.5-4B thinking parity and not justification by itself for a 300–800M scale-up.
