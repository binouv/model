# G18W latent workspace pilot

Finite paired mechanistic pilot registered after G16PR2 failed to replicate the LSD-first serialization signal. It compares final-only supervision, an order-destroying bag-of-states auxiliary target, and chronological latent execution-state supervision at four constant workspace marker positions.

This is a small scratch-trained probe, not the 300–800M target and not evidence of Qwen parity. Gold intermediate states are used only in the training auxiliary objective and post-hoc diagnostics; free-generation scoring receives prompt strings only.
