# L100K (2026-10-12) — registered BEFORE training

**Hypothesis:** A tiny learned byte-query binding circuit improves query-change pair accuracy for last-write memory tasks versus an otherwise identical **query-blind** ablation.

**Status at publication: preregistered; no training/evaluation claim.** Parent is the real verified L100EC curriculum BF16 checkpoint SHA256 `07e33eb2c6aab5727fbb72c0b403bc83ca8e5695d379106af089b27baf995b25` (100,028,328 parameters, frozen). This experiment does NOT retrain that 100M LM; it trains a separate narrow neural memory circuit. Existing L100DA, L100CS, L100QL and L100V runs are untouched.

Architecture: trainable 128×16 byte embedding, 4-position context scorer 64→48→1, learnable query/key distance coefficient, learnable recency; source position classification followed by deterministic byte copying. At inference the scorer receives raw ASCII bytes only, no labels/regex key lookup/answer candidates/solver. Input contract `a=120;b=45;a=7?b`, one ASCII-letter key per record, digit values, semicolon-separated chronological writes. The byte copying loop is an explicitly engineered operator; this is NOT open-domain language generation.

Data: 8192 deterministic train bank groups, two query variants per bank; 64-query minibatches; seeds init/train=121203; AdamW lr=0.003, clip1, weight_decay=0.0001; **1024 updates per arm**; local CPU. Control suppresses query matching (structurally query-blind, an intentionally restricted ablation). Same ordered training batches, fixed end, checkpoint every64 steps. Held groups generated independently: IID 200 pairs seed121204, longer bank 100 pairs seed121205, letters wxyz not used as training keys 100 pairs seed121206, numeric extrapolation 5–6 digits 100 pairs seed121207; train uses letters a-v, values2–3 digits, lengths7–12. Samples are grouped by memory bank, never split query variants.

Primary metric: exact **both-correct query-change pairs** on IID; primary success gate **>= +10pp**, paired bootstrap 95% lower bound >0 (10,000 replicates seed121208), disclose all split outcomes, failures, raw predictions. Same source position labels in training, none at inference. General Qwen3.5-0.8B superiority **is not tested or claimed** by this run. Code and binary adapter must be published with SHA256 according to `FLYGRAPH_RUN_POLICY.md`, parts strictly <90MB. Intermediate checkpoints are `in_progress`; a completed paired result must be saved before declaring a verdict.
