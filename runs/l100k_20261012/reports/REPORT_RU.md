# FlyGraph L100K — завершённое парное обучение нейронного контура памяти

## Статус

Дата: 12 октября 2026. Зарегистрирован до обучения: [REGISTRATION.md](https://github.com/binouv/model/blob/main/runs/l100k_20261012/REGISTRATION.md), commit `fb20bebccf4770c014840a8c3e534a254b08fc2c`. Две ветки по **1024** фактических шага AdamW, batch64 (32 банка × 2 запроса), CPU; реальный FP32 checkpoint, optimizer, Torch RNG и sampler сохранены каждые64 шага. Непрерывность обучения подтверждена 6/6 инженерными тестами, включая побитовое совпадение следующего шага двух reload. Модели: **5219 параметров** каждая. Веса L100EC 100,028,328 параметров сохранены неизменными (SHA256 07e33eb2c6aab5727fbb72c0b403bc83ca8e5695d379106af089b27baf995b25). **Обучался только новый маленький специализированный контур, не основная LLM.**

Главный зарегистрированный критерий: **100 п.п.**, парный bootstrap 95% [100; 100] п.п., успех по заранее выбранным условиям: True. Bootstrap 10,000 повторов по группам (банкам), без просмотра held при выборе checkpoint. Выделенные наборы не пересекаются с обучающими строками по serialized bank SHA; см. SUMMARY.json.

Дополнительная проверка ДО обучения (posthoc engineering diagnostic, не критерий выбора): случайно инициализированная query-aware модель получила 113/400 правильных IID ответов и 1/200 пар, в обученном виде — 400/400 и 200/200 пар. Следовательно, по этому конкретному набору измерено улучшение после оптимизации, а не только архитектурный prior. Все четыре теста построены из фиксированного сериализатора `a=12;b=34;a=56?b`. Проверка на ранее невиденных символах wxyz: 54/100 пар, что показывает ограничение способности переносить равенство ключей.

## Границы применимости

Контур **не является самостоятельной LLM** и не способен произвольно объяснять, писать Python или отвечать по-русски/английски. Он работает с одним форматом ASCII-записей и длиной ключа один символ. Он по обученным весам выбирает позицию, затем **инженерно копирует** последовательность цифр до первого нецифрового байта. Это специализированный retrieval tool: разбор значения здесь НЕ целиком нейронная генерация. Контроль специально лишён информации о ключе, поэтому разрыв с ним не является неожиданным доказательством универсального интеллекта. **Превосходство над Qwen3.5‑0.8B не достигнуто и на этом эксперименте не проверялось.** Нет Qwen inference, длинного естественного текста, кода или независимого внешнего бенчмарка.
