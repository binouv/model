# G4S — завершённая проверка prefix attention

Все шесть моделей завершили по 800 обновлений. Три парные инициализации 7501/7502/7503, по 469648 активных и обучаемых параметров, одинаковые minibatches, данные и objective. Это отрицательный результат данной короткой проверки, а не доказательство бесполезности prefix-attention. Обе модели близки к уровню пола; 800 обновлений на более широком числовом диапазоне недостаточны для широких архитектурных выводов.
